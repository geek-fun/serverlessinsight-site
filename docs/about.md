# 关于我们

ServerlessInsight 是开源的全栈 Serverless 应用平台，帮助团队用一份声明式 YAML 定义、校验并增量部署跨云资源。

## 我们在做什么

云厂商的 Serverless 产品能力在收敛，但配置模型并不统一：函数、网关、对象存储、数据库在阿里云、腾讯云、火山引擎上的写法各不相同。团队换一朵云，往往意味着重写一套部署脚本与运维流程。

ServerlessInsight 把这件事抽象成一层：

- **一份配置** — 用 YAML 声明函数、网关、桶、数据库、事件与域名绑定
- **多云执行** — 同一份配置按 provider 落地到阿里云 FC3 / API 网关 / OSS、腾讯云 SCF / COS、火山引擎 veFaaS / TOS
- **增量与可核验** — 解析、校验、变更预览、执行、状态记录形成闭环，部署状态按服务 / 阶段 / 地域隔离
- **可回滚** — 每一次部署都有明确的状态归属，破坏性操作经过确认才执行

## 技术理念

| 原则 | 含义 |
| --- | --- |
| 声明式优先 | 用户描述"要什么"，而不是"怎么做"；工具负责差异计算与执行顺序 |
| 云厂商中立 | 抽象层与具体 provider 解耦，新增云支持不影响既有配置 |
| 可观测 | 部署过程、状态变更、失败原因都以可核验的形式记录 |
| 开源可审计 | 核心能力开源（Apache-2.0），任何人可以查看实现并参与改进 |

## 产品形态

| 形态 | 用途 |
